# Материалы 3D-редизайна

Центральный 3D-портрет сохранён из предоставленного пользователем референса в `/home/ubuntu/webdev-static-assets/creator-avatar.webp`. Исходный материал имеет разрешение **1450 × 1570 px** и подходит для вертикальной композиции главного экрана; он будет размещён с затемняющим градиентом, чтобы типографика и CTA оставались читаемыми.

Дальнейшие декоративные элементы будут строиться средствами CSS и анимации интерфейса, чтобы не смешивать пользовательские 3D-материалы с непроверенными внешними источниками.
