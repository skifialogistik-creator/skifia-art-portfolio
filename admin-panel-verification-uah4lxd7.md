# Проверка скрытой админ-панели

Публичная главная страница продолжает отображать дизайн, видео, проекты и CTA после перехода на DB-backed контент. Неавторизованное открытие `/studio-control` показывает только закрытый экран входа; публичный интерфейс не содержит ссылки на этот маршрут.

Серверная проверка покрывает три сценария: администратор может читать настройки, администратор сохраняет содержимое, которое затем доступно публичному сайту, а обычный пользователь получает `FORBIDDEN` при попытке редактирования. Итоговый набор: **12 тестов пройдены**, один тест внешних учётных данных пропущен.

После усиления owner-only проверки сервер дополнительно запрещает доступ даже другому пользователю с ролью `admin`, если его `openId` не совпадает с `OWNER_OPEN_ID`. Мобильный снимок скрытого маршрута подтверждает, что закрытый экран входа и CTA корректно помещаются в viewport 375 × 812. Инструкция `admin-guide-uah4lxd7.md` перечитана после финальной правки: она соответствует текущему адресу панели, строгой проверке владельца и разделам редактирования.
