# Интерактивная проверка: 3D-редизайн

Автоматизированная браузерная проверка подтвердила работу магнитного портрета: после движения курсора вычисленный `transform` изображения стал матрицей с ненулевым смещением по X и Y. Прокручиваемая витрина также изменила своё преобразование после скролла, а первая карточка проектов закрепилась на высоте **96 px** от верхней границы экрана.

В контексте `prefers-reduced-motion: reduce` центральный портрет сохранил преобразование `none`, а строка галереи не изменила позицию после прокрутки. Таким образом, дополнительные движения корректно отключаются для пользователей, предпочитающих уменьшенную анимацию.
