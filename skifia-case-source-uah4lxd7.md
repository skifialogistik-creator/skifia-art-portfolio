# Исходные данные первого кейса Skifia

Опубликованный сайт [Skifia](https://skifia.online/) — лендинг транспортных услуг по Польше. На первом экране использованы тёмная сцена, яркая многоцветная типографика и CTA расчёта стоимости. Содержание показывает перевозку мебели, паллет, переезды, стройматериалы и регулярные рейсы для бизнеса; также представлены калькулятор и форма заявки.

Для кейса выбраны реальные скриншоты первого экрана и блока с сервисным предложением. Краткое описание результата будет ограничено наблюдаемыми элементами: информативный первый экран, структура услуг, калькулятор ориентировочной стоимости и форма заявки.

Скриншот первого экрана подготовлен как реальное изображение опубликованного сайта. Первая попытка получить второй экран через прямой hash-якорь вернула пустой тёмный кадр; он исключён и будет заменён только подтверждённым реальным захватом раздела услуг.
