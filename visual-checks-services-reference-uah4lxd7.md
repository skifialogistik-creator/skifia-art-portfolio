# Визуальная проверка: сцена «Услуги»

Новый белый блок использует предоставленный ролик с хромированным кинетическим объектом в качестве полноэкранного фона. Визуальный объект расположен слева, а счётчики этапов — справа; контрастная белая вуаль сохраняет читаемость чёрной типографики.

Внутри блока добавлены поэтапное появление верхней навигации, статистики и нижних текстовых блоков, а также последовательное раскрытие трёх строк заголовка «Смелые / сайты / под ключ». Основные CTA ведут к существующему брифу.
